# Excel Purchasing Data Analysis 📊

## 📌 Project Overview

This project is an **Excel-based Data Analysis project** focused on analyzing purchasing data, products, quantities, and purchasing prices.

The workbook contains product-level and person-level summaries that can be used to understand purchasing activity, product demand, and purchasing value.

## 🎯 Project Objectives

- Analyze the quantity of products purchased.
- Analyze total purchasing prices.
- Compare purchasing activity between different people.
- Identify the products with the highest quantities.
- Identify the products with the highest purchasing value.
- Extract useful business insights from the data.
- Practice Excel data analysis and PivotTable techniques.

## 📂 Dataset

The Excel workbook contains purchasing-related fields including:

| Field | Description |
|---|---|
| **Customer / Person** | Person associated with the purchasing activity |
| **Product** | Purchased product |
| **Quantity** | Number of units |
| **Purchasing Price** | Purchasing value |

The workbook also contains summary/PivotTable sections for analyzing the data from different perspectives.

## 📊 Main Analysis

The workbook provides analysis of:

### 1. Quantity by Person
Shows the total quantity associated with each person.

### 2. Purchasing Price by Person
Shows the total purchasing price associated with each person.

### 3. Quantity by Product
Shows the total quantity for each product and helps identify the most frequently purchased products.

## 🔎 Business Questions

The analysis can answer questions such as:

- Who has the highest purchasing quantity?
- Who has the highest total purchasing price?
- Which products are purchased the most?
- Which products contribute the highest purchasing value?
- Which products have relatively low demand?
- How is purchasing activity distributed across people and products?
